Import MJCF geom `condim` and USD `mjc:condim` into `SolverSteel`'s `steel:condim` as well as `mujoco:condim` (an authored USD `newton:steel:condim` still wins), so an imported condim of 4 or 6 adds Steel's spin and rolling friction rows to free-body contacts; condim 1 imports as 3. Such models now raise `NotImplementedError` on CPU, where these rows are unavailable, as an explicitly set `steel:condim` does; call `model.steel.condim.fill_(3)` before constructing the solver to run them there. A condim above 3 on shapes that no free-body contact reads, such as articulated links or prescribed kinematic bodies without a responding free body, no longer enables the rows.
