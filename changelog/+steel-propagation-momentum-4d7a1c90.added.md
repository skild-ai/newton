Add `propagation_momentum` to `SolverSteel`: with the propagation response, Nesterov momentum accelerates the sweeps, and each tree propagation installs the momentum's move with the sweeps' impulses. The momentum restarts when the sweeps move against it or reverse its last step, so a mode the sweeps overshoot (a light cable link pinched between gripper jaws) is not amplified. The split sweep keeps each row's share of a long tree's mobility small, so a cable lying on a surface and pushed or held converged slowly. Momentum recovers much of that convergence at the same iterations. It is on by default when the model has rod material. The cable bundle example now sweeps 20 times per substep and propagates every iteration, so its Dahl bundle keeps the curvature its obstacles bend in, which the example's own check now asserts under native Steel too.
